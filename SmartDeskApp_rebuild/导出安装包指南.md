# SmartDeskApp 导出安装包指南

## 前提:安装 MATLAB Compiler(当前缺失)

检查命令(MATLAB 命令行): `ver('compiler')` — 显示版本即已安装;
显示 COMPILER_NOT_INSTALLED 则需补装。

补装方法:
1. Windows 开始菜单运行 "MATLAB R2026a 安装程序"(或从 mathworks.com
   账户中心重新下载安装器),登录同一 MathWorks 账号
2. 安装类型选"仅安装所选产品",勾选 **MATLAB Compiler**
3. 完成后 MATLAB 命令行运行 `ver('compiler')` 确认

## 一键打包(装好 Compiler 后)

MATLAB 命令行运行:

```matlab
cd('D:\Matlab\work')
build_package
```

脚本自动执行两步:
1. `mcc -m` 把 SmartDeskApp.m 编译成独立 SmartDeskApp.exe
2. `compiler.build.standaloneWindowsApplication` 生成安装包

产物(在 D:\Matlab\work\package\):
- **SmartDeskAppInstaller.exe** — 给目标机器用的安装程序,
  安装时可自动下载/捆绑 MATLAB Runtime R2026a(目标机免装 MATLAB)
- 编译版 exe — 独立运行,只依赖 Runtime

## 分发给别人的两种方式

方式 A(推荐):把 Installer.exe 发给对方,双击安装。首次安装会联网
下载 MATLAB Runtime(约 2-3 GB),之后完全离线运行。

方式 B:绿色版。把 for_redistribution_files 文件夹整个拷给对方,
但对方机器需已装 MATLAB Runtime R2026a(可从 MathWorks 官网免费下载)。

## 注意事项

- 语音功能(System.Speech)在编译版中正常可用,目标机为 Windows 即可;
  无麦克风时自动降级模拟模式,不影响其他功能
- 编译版不再需要目标机装任何 MATLAB 组件(除 Runtime)
- 换电脑运行时 Windows Defender SmartScreen 可能提示未知发布者,
  点"仍要运行"即可(个人/学术用途无需购买代码签名证书)
