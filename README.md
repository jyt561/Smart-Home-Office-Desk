# Smart-Home-Office-Desk
MATLAB-based smart home office desk control system with seven functional modules (A–G).
Overview
An interactive MATLAB control interface developed as part of doctoral research in Art and Design at UWTSD.
Features
A–G: Seven core functional modules, including posture, lighting, safety, environmental regulation, object management, privacy and multi-scenario switching.

H: Additional voice-control interface.
Setup
Requirements: MATLAB R2023a or later. Windows is required for the documented speech-recognition functions.
